# 用 QCam 讲这次改造

建议题目：**旧像素时钟，变成 Codex 桌面看板**。

QCam 是本人录制口播的工具，内容主线是“旧设备如何重新进入日常工作”。先拍约两分钟的竖屏版本，实物与操作做主要证据。

| 顺序 | 讲什么 | 拍什么 |
| --- | --- | --- |
| 1 | 这只旧时钟现在能显示三只猫 | 实物三猫动画，先给结果 |
| 2 | 原连接方式失效后如何排查 | 本人讲述；家庭网络信息不入镜 |
| 3 | 先恢复联网，再连本地服务 | 一张简单的数据流图，保留原固件 |
| 4 | 额度、累计 Token、14 天活动有什么用 | 实物动画＋明确标记为演示数据的网页 |
| 5 | 别人如何复现 | 仓库 README、`npm run demo`、画面切换 |
| 6 | 适配范围与使用条件 | 已验证型号、主机需运行、自然告别 |

讲述限制：只有一款设备的实测，不声称通用恢复所有时钟；原云端天气、小程序问题没有被这个显示服务解决。浏览器截图不是实物运行证明，演示数据不是作者真实账号统计。

## 录制前

- 录本人 QCam A-roll 和时钟实拍，分开留原件。当前仓库不包含真人素材或已剪辑的视频。
- 电脑录屏优先使用 `npm run demo`。确保“演示数据”标记可见，别录入登录信息、真实账号用量、家庭 IP、Wi-Fi 名称或密码。
- 32×8 小屏先试拍，降低曝光，锁定白平衡；检查滚动条纹、频闪与颜色，不把网页预览替代实物特写。
- 口播稿只放可直接念的句子，镜头提示另放。剪辑以本人连续原声为时间轴，保持切换前后的嘴型同步。
- 人物画中画只放在不挡产品和字幕的位置，没有安全位置就隐藏。

视频是否已经录制、剪辑、导出和发布，分别核验；源码发布不代表视频也已发布。
