# 数据口径

本服务只启动本机已安装的 `codex app-server`，初始化后请求 `account/rateLimits/read` 和 `account/usage/read`，不读取登录文件、不扫描对话日志，也不调用模型生成。账户读取本身可能需要 Codex 联网。

| 画面 / 指标 | 字段与规则 |
| --- | --- |
| 剩余额度 | 优先主 `codex` 限额桶，剩余为 `100 - usedPercent`；窗口按实际分钟数识别，Spark 单独处理，不混入主额度 |
| 重置倒计时 | 同一额度窗口的 `resetsAt`；过期或缺失不显示零 |
| 累计 Token | `usage.summary.lifetimeTokens`，不以单会话总量替代 |
| 每日活动 | `usage.dailyUsageBuckets`，按 `startDate` 和非负数值 `tokens` 读取 |
| 近 14 天 | 上海当前日期和前 13 个日期；保留接口日期标签，不猜测小时分布或换算未提供的时区信息 |
| 已记录合计 | 只加总本窗口内确实返回的每日数据；缺失日期不视作零 |
| 活跃天数 | 已知且 `tokens > 0` 的日期数，不推断未返回日期 |
| 柱高 | 相对这 14 天内已知峰值的线性比例，LED 高度向整数像素取整 |

`null` / 未返回和明确的 `0` 始终不同。所有数据缺失时显示 `--` 或空态。失败后最近有效值会标为待更新，超过 5 分钟移除；额度重置时间已过则直接隐藏。

累计 Token 是接口报告的历史用量，不能据此推算剩余次数、费用、现金或账单。接口返回范围与更新时间由 Codex / 账号能力决定；今天没有记录不代表今天没有使用。

`--demo` 使用虚构数据，页面醒目标记 `演示数据 · 未连接实物`；不会调用账户客户端或打开 MQTT。
